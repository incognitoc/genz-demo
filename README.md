# 饌保堡工作管理系統 — POC

派工與技能點數管理系統的可點擊原型（一般員工端），供客戶檢視流程與視覺方向。

## 檢視方式

- **線上**：GitHub Pages（見本 repo Settings → Pages 後產生的網址）
- **本機**：直接用瀏覽器開啟 `index.html`，任意帳密即可登入

## 內容範圍

單一 `index.html`，純前端、無後端，資料皆為展示用假資料。

工作分為「本薪工作」與「加值工作」兩類。

全部畫面均已模擬完成：登入、首頁、認領工作、工作詳情、工作台、交件、交件完成、我的工作（本薪／加值・未完成／已完成）、歷史紀錄、我的點數、部門達成率、通知中心、我的技能、申請技能驗證、設定、說明與規則。

主要流程：
- 認領工作 → 工作台 → 交件（上傳＋版本說明）→ 交件完成 → 審核 → 領取點數
- 我的技能 → 申請技能驗證（等級、佐證、驗證人）→ 送出
- 設定：個人資料、可工作時段、工作負載上限、通知偏好、主題、登出（皆可互動）

篩選：認領工作、我的工作、通知中心、歷史紀錄的分類篩選皆可實際過濾。

## 技術

- 無建置流程，開檔即用
- 字型：Google Fonts（Outfit、Noto Sans TC）
- Icon：Font Awesome 6（cdnjs）
- 響應式：Mobile 375 / Pad 1024 / Desktop 1440，支援深／淺色

## 授權

內部提案用途，未開放散布。

## 第二版：Sky Office（完整房間版）

全部 16 個頁面使用各自不同的寫實高樓室內場景，並提供 3D 透視鏡頭轉場。保留原型既有工作、點數、通知、技能、設定等操作。

快速連續切換會取消前次動畫；系統啟用減少動態效果時直接切換。場景按需載入，下載失敗會保留最後可用背景並維持頁面操作。

發布：執行 `sh build.sh` 產生靜態輸出，也可使用 GitHub Pages 直接發布根目錄。
